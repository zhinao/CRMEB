# 视频轮播功能使用说明

## 概述
已将原有的图片轮播功能改为MP4视频播放功能。修改了以下组件：

1. `pages/index/visualization/components/swiperBg.vue` - 可视化模式轮播组件
2. `pages/index/diy/components/swiperBg.vue` - DIY模式轮播组件  
3. `components/swipers/index.vue` - 通用轮播组件

## 主要功能特性

### 视频播放功能
- ✅ 自动播放视频
- ✅ 支持静音播放
- ✅ 显示播放控制器
- ✅ 支持全屏播放
- ✅ 点击视频可跳转到指定页面

### 自动切换功能
- ✅ 视频播放完毕自动切换到下一个视频
- ✅ 支持手动点击指示器切换视频
- ✅ 视频播放时暂停自动切换
- ✅ 视频暂停时恢复自动切换
- ✅ 可配置切换间隔时间（默认8秒）

### 指示器样式
- ✅ 支持圆点指示器
- ✅ 支持线条指示器  
- ✅ 支持数字指示器（如 1/5）
- ✅ 指示器背景半透明，提升视觉效果

## 数据格式要求

视频数据应该包含以下字段：

```javascript
{
  img: "视频文件URL（MP4格式）",
  poster: "视频封面图片URL（可选）", 
  link: "点击视频时跳转的页面URL",
  info: [
    {},
    { value: "跳转页面路径" }
  ]
}
```

## 配置参数

### 视频播放参数
- `autoplay`: 自动播放（默认true）
- `loop`: 循环播放（默认false，播放完切换下一个）
- `muted`: 静音播放（默认true）
- `controls`: 显示控制器（默认true）

### 自动切换参数
- `interval`: 切换间隔时间（默认8000ms）
- `duration`: 切换动画时长（默认500ms）

## 使用注意事项

1. **视频格式**: 确保使用MP4格式的视频文件，兼容性最好
2. **文件大小**: 建议视频文件不要过大，影响加载速度
3. **网络环境**: 在网络较差的环境下，建议提供封面图片
4. **自动播放**: 部分浏览器可能限制自动播放，建议配置静音播放
5. **性能优化**: 多个视频同时存在时，只播放当前显示的视频
